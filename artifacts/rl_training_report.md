## 1. RL 환경 및 보상 함수 설계 요약

### 1.1 오라클 (사전 계산)

| 오라클 | 타입 | 타겟 변수 | 출력 | 학습 알고리즘 |
|---|---|---|---|---|
| 메인 오라클 | 분류기 | `future_ret_15 > 0` | 상승 확률 `xgb_prob ∈ [0,1]` | XGBoost Classifier |
| 보조 오라클 | 회귀기 | `future_ret_15` (raw) | 예상 log-return `ridge_pred` | Ridge Regressor |

**사전 계산 방식**: 전체 데이터프레임에 대해 오라클 추론 결과를 열로 추가한 뒤

### 1.2 상태(State) 설계

```
obs ∈ R^{10 × 69 + 2} = R^{692}

  [ (scaled 67 features + xgb_prob + ridge_pred) × window_size  |  position  |  unrealized_pnl_bps ]
     ────────────────── 690 dim ───────────────────────────────   ─── 2 dim ───
```

- **window_size**: 10 (과거 10분 슬라이딩 윈도우)
- **피처 스케일링**: RobustScaler (Train 구간 fit, 전체 transform)
- **position**: 현재 보유 포지션 ∈ [-1, 1]
- **unrealized_pnl_bps**: 진입가 대비 미실현 손익 (단위: bps)

### 1.3 액션(Action) 설계

```
a_t ∈ Box(-1.0, 1.0, shape=(1,))

  -1.0 = 풀 숏 (Short 100%)     0.0 = 포지션 청산/관망     +1.0 = 풀 롱 (Long 100%)
```

- 연속형 공간 → 포지션 크기와 방향을 동시에 결정
- **Δpos** = target_position − prev_position

### 1.4 보상(Reward) 함수

$$
r_t = \underbrace{p_t \cdot \log\!\left(\frac{P_{t+1}}{P_t}\right) \times 10^4}_{\text{1-step PnL (bps)}}
    - \underbrace{|\Delta p_t| \cdot f \times 10^4}_{\text{수수료}}
    - \underbrace{\lambda \cdot \Delta p_t^2}_{\text{휩소 패널티}}
$$

| 기호 | 의미 | 값 |
|---|---|---|
| $p_t$ | 현재 포지션 | ∈ [-1, 1] |
| $P_t$ | t봉 종가 | — |
| $f$ | 단방향 수수료율 | 0.05% |
| $\lambda$ | 휩소 패널티 계수 | 0.001 |
| $\Delta p_t$ | 포지션 변화량 | — |

- 보상 단위: **bps (basis points, 1/100%)** → 해석 가능한 스케일 확보
- 이차 휩소 패널티: 소폭 조정은 관용, 급격한 방향 전환은 강하게 억제
