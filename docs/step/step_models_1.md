  완성 내용                                                                                                                                                                     
                                                                                                                                                                                
  scripts/compare_models_arena.py — 410줄의 완전 실행 가능한 아레나 스크립트.                                                                                                   
                                                                                                                                                                                
  실행 방법                                                 
                                                                                                                                                                                
  # 전체 실행 (8개 모델, 기본 30에폭)                       
  poetry run python scripts/compare_models_arena.py                                                                                                                             
  
  # 스모크 테스트 (15K행, 5에폭, ~3분)                                                                                                                                          
  poetry run python scripts/compare_models_arena.py --smoke_test
                                                                                                                                                                                
  # ML 전용 빠른 비교 (~5초)                                                                                                                                                    
  poetry run python scripts/compare_models_arena.py --no_dl
                                                                                                                                                                                
  # DL 에폭 조정                                            
  poetry run python scripts/compare_models_arena.py --epochs 50 --patience 8                                                                                                    
                                                                                                                                                                                
  스크립트 구조
                                                                                                                                                                                
  ┌───────────────────────────┬──────────────────────────────────────────────────────────────┐                                                                                  
  │           섹션            │                             역할                             │
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤                                                                                  
  │ DataBundle + load_data()  │ 80/10/10 시간순 분할, RobustScaler, 분류/회귀 타겟 동시 생성 │
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤
  │ ModelResult               │ 8개 공통 + 분류/회귀 전용 지표를 담는 dataclass              │                                                                                  
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤                                                                                  
  │ _eval_clf / _eval_reg     │ 분류·회귀 공통 평가 로직 분리                                │                                                                                  
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤                                                                                  
  │ _latency_ml / _latency_dl │ 중앙값 기반 레이턴시 측정                                    │
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤                                                                                  
  │ _train_dl                 │ BCE / GMADLoss 겸용 공통 DL 학습 루프                        │
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤                                                                                  
  │ _ArenaDataset             │ stride 지원 슬라이딩 윈도우 Dataset                          │
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤                                                                                  
  │ run_* × 8                 │ 각 모델 학습 → 평가 → del + gc.collect() 해제                │
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤                                                                                  
  │ build_leaderboard         │ 방향정확도(필터↑) 기준 자동 정렬                             │
  ├───────────────────────────┼──────────────────────────────────────────────────────────────┤                                                                                  
  │ save_leaderboard          │ artifacts/arena_leaderboard.csv + .md 저장                   │
  └───────────────────────────┴──────────────────────────────────────────────────────────────┘                                                                                  
                                                            
  설계 핵심                                                                                                                                                                     
                                                            
  - 공정 비교 기준: |future_ret_15| ≥ 0.01% 필터 방향정확도가 RL 오라클 선발 핵심 지표                                                                                          
  - ML vs DL 타겟 정렬: ML은 flat row마다, DL은 슬라이딩 윈도우(60봉)마다 동일 future_ret_15 타겟
  - 누수 방지: 분할 → ffill → train median fill → scaler fit 순서 엄수                                                                                                          
  - OOM 방지: 각 모델 완료 후 del model; gc.collect(); cuda.empty_cache() 3단계 해제
