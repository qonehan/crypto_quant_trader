# 📊 퀀트 트레이딩 봇 실험 결과 보고서 (2026-03-06)

## 1. 데이터 구조 (Data Architecture)
본 모델은 단순 호가창을 넘어, 글로벌 자금 흐름과 시장 참여자의 기세를 반영하기 위해 **4대 원천 데이터 하이브리드 병합 파이프라인**을 구축하여 사용했습니다.

### 1.1. 하이브리드 로드 파이프라인
과거 백업 데이터(Parquet)와 실시간 라이브 데이터(GCP DB)를 `try-except` 및 `ffill()` 보간 로직을 통해 내결함성(Fault Tolerance)을 갖춘 형태로 1초 단위(`1s`)로 병합했습니다.
- **Upbit Orderbook:** 호가창 중간가(`mid`), 스프레드(`spread_bps`), 상위 5호가 불균형(`imb_notional_top5`)
- **Upbit Tick:** 1초간 총 체결량(`total_volume`), 매수 우위 비율(`buy_volume_ratio`)
- **Binance Derivatives:** 글로벌 롱/숏 비율(`long_short_ratio`), 펀딩비(`funding_rate`), 미결제약정(`open_interest`)
- **Macro & Sentiment:** 달러 인덱스(`dxy_index`), 공포/탐욕 지수(`fear_greed_index`)

### 1.2. 피처(Feature) 및 타겟 구성
- **학습 데이터양:** 20시간 (약 72,000개의 1초 캔들)
- **입력 피처 수:** 총 19개
- **경제적 제약(Econ Gate):** `cost_roundtrip_est` (업비트 왕복 수수료 0.1% + 실시간 스프레드)를 피처에 포함하여 수수료 계산 적용.

## 2. 모델 구조 (Model Architecture)
경제적 게이트(Econ Gate)를 통과하는 실전 수익성을 검증하기 위해 두 가지 모델을 비교 훈련했습니다.

1. **Ridge (선형 릿지 회귀):** 복잡도를 낮춰 과적합을 방지하고 변수 간의 선형적 관계를 빠르게 파악하는 베이스라인 모델.
2. **HGBR (HistGradientBoostingRegressor):** 비선형 패턴과 복잡한 시장 구조를 포착하기 위한 트리 기반 앙상블 모델.

> **💡 핵심 로직 (Econ Gate):** 모델이 예측한 기대 수익(Expected Return)이 `cost_roundtrip_est`를 넘지 않으면 무조건 거래를 포기(`STAY_FLAT`)하도록 설계됨.

## 3. 실험 결과 (Horizon Test Results)
예측 호흡(Horizon)을 2분, 10분, 1시간으로 점진적으로 늘려가며 모델의 타점과 수수료 극복 능력을 테스트했습니다.

### 🧪 Test 1: 초단타 (Horizon = 120초 / 2분)
- **Ridge:** 방향 적중률(sign_acc) **57.67%** / IC 0.071
- **HGBR:** 방향 적중률(sign_acc) 47.38% / IC -0.014
- **거래 횟수 (Trades):** 0회 (Ridge, HGBR 공통)
- **분석:** Ridge 모델이 57%라는 훌륭한 적중률을 보였으나, 2분이라는 짧은 시간 내의 변동폭이 수수료(0.1%)를 넘지 못해 모델 스스로 모든 거래를 포기(필터링)함. **(Econ Gate 정상 작동 확인)**

### 🧪 Test 2: 단기 스윙 (Horizon = 600초 / 10분)
- **Ridge:** 방향 적중률(sign_acc) **70.96%** / IC 0.421
- **거래 횟수 (Trades):** 10회 (모두 Short)
- **수익률 (PnL):** Gross PnL 0.007 (승률 70%) ➡️ **Net PnL -0.004 (승률 20%)**
- **분석:** 호흡을 늘리자 예측력(IC)이 0.42로 폭발적으로 상승하며 10번의 거래를 시도함. 원천 방향은 70%를 맞혔으나(Gross), 평균 수익 폭이 수수료를 완벽히 압도하지 못해 수수료 차감 후(Net) 승률은 20%로 급락하며 최종 마이너스 수익 발생.

### 🧪 Test 3: 중기 스윙 (Horizon = 3600초 / 1시간)
- **Ridge:** 방향 적중률(sign_acc) **82.65%** / IC 0.535
- **거래 횟수 (Trades):** 3회 (모두 Short)
- **수익률 (PnL):** Gross PnL 0.015 (승률 100%) ➡️ **Net PnL +0.011 (승률 100%)**
- **분석:** 호흡을 1시간으로 늘린 결과, 거래 횟수는 3번으로 줄었으나 **수수료를 내고도 남을 만큼 확실하고 큰 하락장만 골라내어 100% 승률과 1.1%의 순수익(Net PnL) 달성.** 수수료 장벽을 극복하는 '타임 프레임 최적화'에 성공함.

## 4. 결론 및 Next Steps
1. **수수료의 벽 (Transaction Cost Barrier):** 높은 예측률(57%~70%)을 확보하더라도, 타임 프레임이 너무 짧으면 수수료에 계좌가 녹는 현상을 데이터로 증명함.
2. **다중 데이터 시너지:** 호가창 단일 데이터에서 4대 원천 데이터(Tick, Binance 추가)로 확장한 후, 선형 모델(Ridge)의 예측력이 비약적으로 상승함(IC 0.535). 
3. **Next Step:** 1시간 단위 최적화 모델(`ridge_model.joblib`)을 활용하여 실시간 모의투자(Paper Trading) 모듈에 연동하고 포워드 테스트(Forward Test) 진행 요망. 또한 수집기 가동 시간을 늘려 충분한 데이터(최소 1개월 이상) 확보 후 시계열 딥러닝 및 HGBR 재학습 권장.
