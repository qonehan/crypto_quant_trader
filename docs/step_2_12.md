# Step 2-12: 비전문가 친화적 대시보드 UI/UX 전면 개편 결과 보고

## 변경 파일

`app/dashboard.py` 전면 재작성

---

## 핵심 변경 구조

```
main()
  └─ st.tabs(["📊 직관적인 요약 (메인)", "🔬 세부 계산 데이터 (전문가용)"])
       ├─ Tab 1 → render_tab1()   ← 비전문가용 신규 설계
       └─ Tab 2 → render_tab2()   ← 기존 전체 내용 이전
```

---

## Tab 1: 직관적인 요약 (비전문가용)

### 구성 섹션

| 섹션 | 내용 |
|---|---|
| 현재 BTC 가격 | mid 가격 + 추세 이모지(📈/📉) + 데이터 지연 표시 |
| AI 모델 정보 | 현재 model_version 표시 |
| **AI의 현재 판단** | action_hat을 색상 배지(HTML)로 시각화 — 매수/관망/매도 즉시 파악 |
| 확률 지표 | p_up, p_down, p_none, EV — 각각 help= 설명 포함 |
| 모의투자 성과 | 추정 총자산(±손익), 포지션 상태, 승률, 거래 횟수 |
| 최근 거래 내역 | 비전문가용 한글 컬럼명으로 변환된 간략 테이블 |
| 자산 변화 곡선 | 최근 6시간 equity_est 라인 차트 |

### action_hat 색상 배지

```python
"ENTER_LONG" → 초록 배지 "🟢 매수 신호 (LONG)"
"STAY_FLAT"  → 회색 배지 "⚪ 관망 중 (WAIT)"
"EXIT_LONG"  → 빨간 배지 "🔴 매도 신호 (EXIT)"
```

### help= 설명 적용 항목

| 지표 | 설명 |
|---|---|
| 현재 BTC 가격 | 업비트 호가 중간가(매수·매도 호가 평균) |
| 데이터 지연 | 마지막 데이터 수신 후 경과 시간, 5초 이하 정상 |
| AI 모델 | 현재 판단에 사용 중인 모델 이름 |
| 상승/하락 확률 | AI가 생각하는 2분 뒤 가격 변동 확률 |
| 관망 확률 | 배리어 미도달 확률, 높을수록 신호 없음 |
| 기댓값 (EV) | 수수료를 빼고도 이득일 때만 거래 |
| 현재 자산 | 현금 + 보유 BTC 환산 추정 총 자산 |
| 승률 | 방향을 정확히 맞혀 수익을 낸 비율 |

## Tab 2: 세부 계산 데이터 (전문가용)

기존 `main()` 함수의 모든 섹션을 `render_tab2()`로 이전:

- 가격 흐름 라인 차트
- [A] 배리어 피드백 (r_t, sigma_h, k_vol_eff 차트 포함) + help= 설명
- [B] AI 확률 지표 (Accuracy, Brier, LogLoss 등) + help= 설명
- [C] 캘리브레이션 테이블 (ECE)
- [D] EV/비용 진단 패널 (수수료 분해)
- 예측 원본 데이터 테이블 (mom_z, spread_bps, imb_notional_top5) + help= 설명
- 평가 결과 테이블
- [E] 모의투자 상세 (낙폭 차트, 거래 통계, 로그, 의사결정 로그)
- [F] Upbit 거래소 연동 (계좌, 주문 로그)
- [G] Alt Data (Binance, Coinglass)

### Tab 2 추가된 help= 설명

| 지표 | 설명 |
|---|---|
| k_vol_eff | 배리어 크기를 결정하는 변동성 배율 |
| none_ewma | 최근 관망 비율의 지수평균 |
| mom_z | 가격 상승/하락 기세 강도 (양수=상승세) |
| spread_bps | 살 때와 팔 때 가격 차이(숨겨진 수수료) |
| Mean Brier | 확률 예측 오차, 0=완벽 1=최악 |
| r_min_eff | 수수료를 고려한 최소 배리어 하한선 |
